關卡 1：精靈圖切格與靜止動畫
---------------

**任務**：畫面中央顯示角色，循環播放 stand.png 的 3 張圖，每張150 毫秒。

**想一想**：`image()`  有 9 個參數：

前 5 個參數：
1. stopSheet：要顯示的圖片。
2. width / 2 - fw / 2：圖片顯示的 X 座標，讓角色水平置中。
3. height - stopSheetHeight：圖片顯示的 Y 座標，讓角色底部貼齊畫布底部。
4. fw：圖片顯示的寬度。
5. stopSheetHeight：圖片顯示的高度。

後 4 個參數：
6. stopFrame * fw：從原圖的哪個 X 座標開始裁切。
7. 0：從原圖的 Y = 0 開始裁切。
8. fw：從原圖裁切的寬度。
9. stopSheetHeight：從原圖裁切的高度。

其中 fw = stopSheetWidth / 3，因為月的站立動畫共有 3 張，每張播放 150 毫秒。
:::spoiler 程式碼


```javascript=


// ==================== 08. 共用動畫繪製 ====================

// 依照指定影格、角色倍率與方向繪製動畫。
function drawSprite(sprite, frame, x, y, scaleValue, direction = 1) {
  if (!sprite || !sprite.img) return;                         // 如果圖片不存在就停止繪製。
  const frameWidth = sprite.img.width / sprite.count;         // 計算原始圖片每一格的寬度。
  const frameHeight = sprite.height;                          // 取得原始圖片每一格的高度。
  const drawWidth = frameWidth * scaleValue;                  // 依角色倍率計算顯示寬度。
  const drawHeight = frameHeight * scaleValue;                // 依相同倍率計算顯示高度。
  const safeFrame = constrain(floor(frame), 0, sprite.count - 1); // 避免影格超出圖片範圍。

  push();                                                     // 儲存目前繪圖狀態。
  translate(x, y);                                            // 將繪圖原點移到角色腳底。
  scale(direction, 1);                                        // 依角色方向決定是否水平翻轉。
  image(                                                       // 從精靈圖裁切指定影格並繪製。
    sprite.img,                                               // 指定要使用的圖片。
    0,                                                        // 將圖片水平置中。
    -drawHeight / 2,                                          // 讓圖片底部落在角色腳底。
    drawWidth,                                                // 設定等比例縮放後的寬度。
    drawHeight,                                               // 設定等比例縮放後的高度。
    safeFrame * frameWidth,                                   // 指定原圖中影格的起始 X。
    0,                                                        // 指定原圖中影格的起始 Y。
    frameWidth,                                               // 指定要裁切的原始寬度。
    frameHeight                                               // 指定要裁切的原始高度。
  );                                                          // 結束圖片繪製。
  pop();                                                      // 恢復原本的繪圖狀態。
}                                                             // 結束共用動畫函式。


```
:::

**問答**：為什麼用 `millis()` 而不是每個 `draw()` 都換格？

> 我的回答：因為 `draw()` 會不斷執行，如果每次執行都換格，動畫就會播放得太快，而且速度會受到電腦效能和畫面更新率影響。使用 `millis()` 可以計算經過的時間，讓動畫每隔固定時間才切換影格，例如原本設定的 150 毫秒，使動畫播放速度更穩定、自然。

**任務**：角色顯示高度 = 畫布高的 1/3，寬度依原圖寬高比縮放；視窗放大縮小時角色不變形。

**算算看**：畫布高 900 時，跑步角色的顯示寬約是多少？（單格寬 ≈193.58、原高 168）

> 我的算式與答案：
> 站立顯示高度 = 900 ÷ 3 = 300
> 縮放倍率 = 300 ÷ 136 ≈ 2.206
> 飛行顯示寬度 = 107 × (300 ÷ 136) ≈ 236.03 像素
> 飛行顯示高度 = 134 × (300 ÷ 136) ≈ 295.59 像素

關卡 6：閃電與爆炸
----------

**任務**：背景到最右端時，在距離視窗右邊 1/4 寬的位置，由上往下打 3 次閃電（每次 1 秒），再在視窗底端播 1 次藍色爆炸（1 秒），不斷重複。

**完成時間軸**：

|     |     |     |     |     |
| --- | --- | --- | --- | --- |
| 時段 (ms) | 0–1000 | 1000–2000 | 2000–3000 | 3000–4000 |
| 畫面 | 第一次閃電 | 第二次閃電 | 第三次閃電 | 藍色爆炸 |
| strikeNumber | 1 | 2 | 3 | 0（爆炸階段） |

:::spoiler 程式碼

```javascript=
const elapsed = millis() - lightningStartedAt;
const cycleElapsed = elapsed % 4000;

if (cycleElapsed < 3000) {

  const strikeNumber =
    floor(cycleElapsed / 1000) + 1;

  const frame =
    floor((cycleElapsed % 1000) / 1000 * 6);

  // 繪製閃電

} else {

  const t = cycleElapsed - 3000;

  const frame =
    min(9, floor(t / 1000 * 10));

  // 繪製爆炸
}
```
:::

**問答**：「距離右邊 1/4」寫成程式是 `width * ____`？

> 我的回答：0.75，因為從畫面左側開始計算，距離右側 1/4 的位置等於畫面寬度的 3/4。

-   3 次閃電後才爆炸，爆炸在畫面底端
-   整組效果會重複播放

關卡 7–8：打雷音效與特效退場
----------------

**任務**

1.  每次閃電出現時播一次 `audio/chrysalyn-clean-dramatic-lightning-crash-547378.mp3`。
2.  背景開始往回捲時，閃電要跟著背景移動，慢慢退出畫面；完全離開後才停止特效與音效。

**想一想**：`draw()` 每秒執行 60 次，如果每次都 `play()` 會發生什麼事？怎麼讓一次閃電只響一次？
:::spoiler 程式碼
```javascript=
// 音效：每次閃電只響一次
const strikeNumber = floor(cycleElapsed / 1000);

if (strikeNumber < 3 && strikeNumber !== lastThunderStrike) {
  thunderSound.play();
  lastThunderStrike = strikeNumber;
}

// 觸發時記下「在背景上」的位置（世界座標）
lightningWorldX = backgroundCameraX + BASE_W * 0.75;

// 每格換算回畫面座標
const effectX = lightningWorldX - backgroundCameraX;

// 特效是否已完全離開畫面右側？
const effectHasExited = effectX - effectDisplayWidth / 2 > BASE_W;

// 音訊必須在使用者操作後啟用（放在 keyPressed 裡）
userStartAudio();
```
:::

**問答**：為什麼不能直接用 `width * 0.75` 當閃電位置？

> 我的回答：我的回答：如果直接使用 width * 0.75，閃電就會固定在視窗寬度的 75% 位置，不會隨著背景移動。因此需要在觸發閃電時記錄它的世界座標，再減去目前的鏡頭位置，讓閃電能夠跟隨背景移動，直到完全離開畫面。

**檢核清單**

-   每次閃電響一聲，沒有重疊爆音
-   背景剛開始動、閃電仍在畫面內時，效果繼續
-   閃電跟著背景滑出畫面後才停
-   再次走到最右端，效果會重新觸發
